\# Noolukunta Village Website



A Django-based website developed for Noolukunta village.



\## Technologies

\- Python

\- Django

\- HTML

\- CSS

\- JavaScript

\- SQLite



\## Features

\- Village information

\- News and updates

\- Activities

\- Gallery

\- Community directory

\- Admin management



\## Run Locally



1\. Install dependencies:

&#x20;  pip install django pillow



2\. Run migrations:

&#x20;  python manage.py migrate



3\. Start the server:

&#x20;  python manage.py runserver



4\. Open:

&#x20;  http://127.0.0.1:8000/
